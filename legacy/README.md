# Heritage Housing Projects — Website Prototype

This is a front-end prototype for Heritage Housing Projects (Pvt) Ltd.

## Included
- Corporate home page
- About, Services, Projects, Properties, News and Contact sections
- Property filtering
- Client portal login/demo dashboard
- Client stand information
- Payment balance and history
- Project progress timeline
- Document area
- Support area
- Responsive mobile layout

## Important production note
The portal in this prototype is intentionally front-end only. A production deployment must replace the demo login and hard-coded client data with a secure backend/database, server-side authentication, role-based access control, encrypted transport/storage, audit logging, secure document access, backups and verified payment integration.

Suggested production stack: WordPress/public CMS + secure application backend/API + PostgreSQL/MySQL + object storage for private documents + HTTPS + role-based authentication. Do not store passwords or sensitive client records in front-end JavaScript.
